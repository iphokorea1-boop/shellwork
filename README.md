# Shellwork

Arky에서 영감을 받은 생각 정리 캔버스입니다. 아이디어를 **셸**(제목 + 본문) 단위로 캔버스에 흩어 놓고,
끌어다 묶어서 계층을 만들면, 같은 트리가 그대로 **문서**와 **마인드맵**이 됩니다.

- 웹사이트: https://iphokorea1-boop.github.io/shellwork/ (보드는 브라우저에 저장, AI·함께 쓰기는 꺼짐)
- AI까지 되는 버전: https://claude.ai/artifact/8iQWLuStXZsvzAGe8mooXV (내 Claude 계정으로 AI, 클라우드 저장, 함께 쓰기)

## 기능

| 기능 | 사용법 |
| --- | --- |
| 셸 만들기 | 빈 곳 더블클릭, `N` 키, 왼쪽 위 "새 셸" |
| 묶기(중첩) | 셸 윗줄(H1/H2 표시)을 잡고 다른 셸 위에 놓기. 셸 위쪽 가장자리에 놓으면 앞에, 아래쪽이면 뒤에 들어감 |
| 빼기 | 하위 셸을 빈 캔버스로 끌어내기, 또는 `Shift+Tab` |
| 화살표 | 셸 오른쪽 위 파란 점을 끌어 다른 셸에 놓기. 화살표를 눌러 고른 뒤 `Delete` |
| 글 붙여넣기 | 캔버스에 `Ctrl+V` 또는 "글 붙여넣기". `#` 제목·`-` 목록은 계층으로, 문단은 셸 하나씩 |
| 문서 보기 | 위쪽 "문서" 탭. 여기서 고쳐도 캔버스에 반영됨 |
| 마인드맵 | 위쪽 "마인드맵" 탭. 노드를 누르면 캔버스의 그 셸로 이동 |
| AI | 셸의 ✦ 버튼(펼치기·다듬기·요약·질문·반론), "AI 구조화", 오른쪽 AI 패널(답변을 캔버스로 끌어 놓기) |
| 내보내기 | 마크다운(.md) 저장/복사 |
| 실행 취소 | `Ctrl+Z` / `Ctrl+Shift+Z` |
| 명령 찾기 | `Ctrl+K` (초성 검색도 돼요), 단축키 전체는 `?` |

## 보드의 규칙

- 셸은 문서의 **제목**, 글 조각은 **문단**이 돼요.
- 셸 안에 셸을 넣으면 제목 단계가 내려가요. 제목은 H1~H6, **6단계까지**만 넣을 수 있어요(마크다운과 같아요).
- 캔버스 위 조각의 문서 순서는 **위에서 아래, 같은 줄은 왼쪽부터**예요. `O` 키나 아래 막대의 번호 버튼으로 순서 번호를 볼 수 있고, 끌어서 옮기는 동안에는 자동으로 보여요.
- **섹션**(배경 묶음)과 **화살표**는 보기 위한 것이라 문서 목차를 바꾸지 않아요.
- 사진으로 만든 셸에는 **출처**(미리보기, 날짜, 쪽 번호)가 붙어요.
- 버전은 작업 중 **10분마다** 자동으로 남고, `Shift+H`에서 이름을 붙여 남기거나 되돌릴 수 있어요.

## 파일 구조

```
index.html      화면 뼈대
style.css       화면 틀 디자인: 사이드바, 떠 있는 도구 막대, 메뉴, AI 패널 (라이트/다크 모드)
canvas.css      셸, 글 조각, 화살표, 문서 보기, 마인드맵, 발표 모드 디자인
js/store.js     데이터 모델: 셸과 글 조각 트리, 셸로 감싸기, 실행 취소, 마크다운 변환, 템플릿
js/persist.js   저장: claude.ai DB 또는 브라우저 localStorage
js/motion.js    애니메이션: 셸이 날아가는 움직임(FLIP), 카메라 이동, 두 가지 스타일
js/collab.js    함께 쓰는 보드: 셸 단위 실시간 동기화, 다른 사람 커서
js/md.js        셸 글의 글머리표·굵게 같은 서식 표시
js/canvas.js    캔버스: 그리기, 화살표, 선택 막대, 집중 모드, 구조 편집
js/input.js     캔버스 조작: 클릭 선택, 끌어서 넣기/빼기, 범위 선택, 화면 이동, 글 편집 키
js/doc.js       문서 보기, 마인드맵
js/present.js   발표 모드
js/ai.js        AI 기능 (claude.ai의 sample 기능 사용, API 키 필요 없음)
js/history.js   버전 기록: 10분마다 자동 저장, 이름 붙인 버전, 되돌리기
js/docx.js      Word(.docx) 내보내기 (라이브러리 없이 직접 만듦)
js/keys.js      단축키, 명령 팔레트(Ctrl+K), 단축키 표(?), 버튼 툴팁, 복사·붙여넣기
js/main.js      시작, 보드 관리, 메뉴
icons/          앱 아이콘 (SVG, PNG, favicon.ico)
.github/workflows/pages.yml   main에 push하면 GitHub Pages로 자동 배포
```

## 내 컴퓨터에서 실행

```bash
python -m http.server 5173
```

브라우저에서 http://localhost:5173 을 엽니다. 이때는 보드가 브라우저에 저장되고 AI는 꺼져 있습니다.
AI와 클라우드 저장은 claude.ai에 Artifact로 게시한 페이지에서 동작합니다.
